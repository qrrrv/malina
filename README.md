## Возможности

- Современный CLI-интерфейс (спиннеры, анимации, шутки как в Claude Code / Codex)
- Создание и редактирование скетчей
- Компиляция
- Заливка прошивки
- Установка библиотек по ссылке с GitHub
- Поддержка Uno / Nano / Mega / Leonardo / Pro Mini / ESP32 / ESP8266

## Установка

### Способ 1 — из zip

1. Скачай и распакуй архив
2. Зайди в папку:
   ```bash
   cd malina
   bash install.sh
   ```

### Способ 2 — после публикации на GitHub

```bash
git clone https://github.com/ТВОЙ_ЮЗЕР/malina.git
cd malina
bash install.sh
```

После установки просто пиши:

```bash
malina
```

## Структура проекта

```
malina/
├── bin/
│   └── malina              # главный запускаемый файл
├── lib/
│   ├── ui.sh               # цвета, спиннеры, анимации, шутки
│   ├── boards.sh           # выбор платы
│   ├── sketches.sh         # создание / открытие / редактирование
│   ├── compile.sh          # компиляция
│   ├── upload.sh           # заливка
│   └── libraries.sh        # библиотеки с GitHub
├── config/
│   └── default.conf
├── install.sh
├── VERSION
└── README.md
```

## Требования

- Termux (рекомендуется с F-Droid)
- USB OTG кабель
- Для заливки без root — TCP UART Bridge (инструкция внутри программы)
